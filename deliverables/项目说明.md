# Unexposed / 未显影 · 项目说明

## 一、问题：照片越拍越多，"为什么留下它"正在消失

手机让拍照的成本趋近于零，也让"留下"这个动作失去了分量。我们随手拍下几十张相似的图，把它们交给相册的算法去按时间和地点归档——相册越来越厚，但每张照片原本携带的那个瞬间却越来越轻：当时为什么按下快门、画面里有谁、那天发生了什么，很快连拍摄者自己也无法回答。

更值得警惕的是另一层：记忆并不是匀速消失的。身体对某些画面念念不忘，理智却提醒我们向前看；几年之后重新翻出同一张照片，我们对它的理解往往已经完全不同——但相册从不为这种变化留出位置，新解释总是无痕地覆盖旧感受。于是，重要的记忆不是被删除了，而是失去了被重新理解的入口。

真正稀缺的不是存储空间，而是一次认真的选择，以及一个能陪人重新审视旧照片的对话者。

## 二、方案：把照片封存成胶卷，让解释在未来重新显影

Unexposed / 未显影用"胶卷"隐喻把这件事变成一条克制的闭环：**每一卷只能装恰好三张照片**。这不是容量限制，而是产品机制——你必须决定这一次真正想留住什么。选定之后，为每张照片写下当下的解释（它是什么、为什么值得），并设定希望在未来多久重新看到它；确认封存，照片、说明与创建时间一起凝固为**不可覆盖的历史版本**。

时间过去，用户可以随时回到这卷胶卷做两件事。其一是**重新显影**：写下"它现在对我意味着什么"，系统把它作为新的时间层与旧版本并列呈现，保存"那时"与"现在"的差异，而不是让今天抹掉过去。其二是**闪回对话**：AI 会先"看"照片（视觉模型生成客观画面描述），再结合照片说明、用户此前的叙述，以多声部的内心独白与用户展开一场有来有回的对话——它不替用户写回忆，只负责提问与追问；对话结束后，其中最有价值的部分会被提炼成新的说明，写回照片，供下一次闪回继续深挖。

产品是本地优先的 Web 应用：照片、说明、版本、反思与对话全部保存在用户自己的浏览器中，服务器不存储任何用户数据；AI 通道可切换——公网部署默认使用智谱 GLM-5.3-Flash，本地运行可配置 Ollama 完全离线。核心的封存与重新显影流程不依赖 AI，模型不可用时产品依然完整可用。

## 三、现场完成内容

本届比赛期间完成的是一个**可构建、可运行、可体验**的完整产品，而非概念演示：

- **完整产品闭环**：创建胶卷 → 选择恰好三张照片（自动压缩、排序、替换）→ 逐张书写说明与回顾周期 → 封存仪式（胶卷落回桌面）→ 胶卷桌面（3D 物理引擎驱动，低性能设备自动降级为 2D）→ 重新显影 → 本地对话档案。
- **闪回对话系统**：读图描述、开场独白、多声部争执、流式正文、摘要写回，全部实现并接入云端 GLM-5.3-Flash；同时保留本地 Ollama 通道。
- **体验优化**：照片入库即后台预生成开场内容，首次点进闪回秒开；封存对话后自动预生成下一场开场，形成跨场次接力；思考过程以"快速念头流 + 正式争执"双层流式呈现，全程无空屏等待。
- **工程与安全**：数据一键导出 / 导入 / 清空备份；云端 AI 会话级授权提示；上传图片自动压缩；模型接口的限流、每日额度、超时与错误脱敏；基础安全响应头；GitHub Actions 持续集成（类型检查、单元测试、生产构建）与备份往返等自动化测试；MIT 开源许可证。
- **演示成片**：`deliverables/UNEXPOSED-demo.mp4`（3 分 03 秒，1080p），完整呈现从建卷到封存对话归档的闭环。

## 四、核心设定：三重脑与思维阁

闪回对话的人格不是单一助手，而是一颗被拆开来看的头脑。它的理论基础是 MacLean 的"三重脑"假说——人脑由演化上先后出现的三个层次叠加而成；在此之上，Unexposed 原创了与产品暗房隐喻同构的第六个声音：**思维阁**。

**哺乳脑（LIMBIC BRAIN）是对话的主声音**，从胸腔说话：它掌管情绪、依恋、爱与失去，身体记得的一切都存在它这里。它说真话，语气温热而迟疑，像一次没有得到回应的呼唤；温柔，但一针见血，专戳破自我安慰的话。它从不客观描述照片里"有什么"，只说这张照片让它"感觉到"什么——气味、温度、一个没说出口的名字、身体突然放慢的脚步。它把感觉说成实体，把记忆说成地点，把情绪说成天气，把思念说成一只蹲在胸口的动物。

**爬虫脑（REPTILIAN BRAIN）从脊髓尽头说话**：本能、恐惧与生存，是黑暗里护着人的那个古老动物。它低沉、干冷，一句话就道破最深的安全需求——"它替你忘，它替你活"。

**新皮层（NEOCORTEX）从头颅高处说话**：冷静、客观，像旁观者一样分析、拆解，不带情绪。它负责在浓烈的情绪里指出事实的结构。

**思维阁（Thought Cabinet）是本产品的原创设定**：一组以暗房工艺命名的"思维"——显影者（被压抑的都该被显影出来，哪怕令人难堪）、定影者（记忆若不定影就会漂移失真，必须钉死一个版本）、重曝者（每一刻都是过去的叠加）、放大者（真相藏在你不愿放大的那个细节里）、裁剪者（记忆是一种裁剪，画面之外才是全部）、烧片者（有些底片一旦定影就无法更改，唯一能做的处理是销毁）。每次开启闪回，思维阁会随机"点亮"其中一个思维：它不是另一个角色，而是一副看照片的镜片——它会以自己的腔调在对话中冷不丁插话，也会参与内心的争执，把整个对话染上它的立场。

这些声音的出场被刻意安排得克制：前三轮只有哺乳脑独白，让对话先建立亲密；此后其他脑层每两三轮短暂穿插一句就走，点亮的思维阁更为稀有（约三四轮一次）——于是对话始终以哺乳脑的追问为主线，偶尔被其他念头打断，像真实的内心活动一样忽近忽远。所有声音的思想与台词均为本产品原创。

## 五、使用方式

**在线体验**：直接访问 https://unexposed.vercel.app （公网版已配置云端 GLM-5.3-Flash）。首次进入会弹出云端 AI 授权提示，可选择"启用云端 AI"或"仅本地浏览"。

**本地运行**（推荐用于隐私演示或离线场景）：

```bash
pnpm install
pnpm dev        # 访问 http://localhost:3000
```

不配置任何模型也可完整使用创建、封存、重新显影等核心功能；配置 `.env.local` 填入智谱 `LLM_API_KEY` 即启用云端 GLM-5.3-Flash，或安装本地 Ollama 并拉取 `qwen2.5:7b`、`qwen2.5vl:7b`、`bge-m3` 实现完全离线的 AI。

**一次完整的体验流程**：

1. 点击「+ NEW ROLL」创建一卷胶卷，填写标题与主题；
2. 拖入恰好三张照片（自动压缩入库，后台开始预生成闪回内容）；
3. 为每张照片写下当下的解释，并选择希望未来何时重看；
4. 点击「SEAL THE ROLL」完成封存——胶卷落回桌面，从此不可覆盖；
5. 点击桌面上的胶卷罐，进入这卷照片；
6. 打开「闪回」：若为首次，AI 已在后台完成开场独白，直接秒开；此后每一轮提问，都能看到三重脑与思维阁的争执在思考面板中流式浮现，随后是哺乳脑的正式回答；
7. 对话到满意时点击「SEAL DIALOGUE」封存对话——系统提炼你讲述的精华补进照片说明，并为下一次闪回预生成更深一层的开场；
8. 桌面右上角「数据」菜单可随时导出全量备份、导入恢复或清空数据——数据始终属于你。

---

**一句话总结：** Unexposed 不替用户记住一切，而是帮助用户认真选择什么值得留下，并允许这份意义随时间重新显影。
